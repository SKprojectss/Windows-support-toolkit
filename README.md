# Windows-support-toolkit

**This repository contains a growing PowerShell-based toolkit designed to practice real-world troubleshooting.**

The project focuses on structured diagnostics and system investigating, including:

*-CPU usage analysis*

*-RAM usage analysis*

*-Windows Update service checks*

*-Disk space monitoring*

*-Additional system and service diagnostics (planned)*

**The long-term goal of this project is to simulate common IT scenarios and build structured troubleshooting workflows using PowerShell.**
